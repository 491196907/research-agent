# Agent 设计笔记（示例资料）

## Agent 循环
Agent 的核心是"想 → 做 → 看"的循环：模型决定下一步做什么，程序执行工具，把结果交回模型，它再决定下一步。
必须设最大步数上限，否则模型可能反复调用同一个工具，陷入死循环。

## 工具设计
工具是模型的手和眼。工具的名字要能一眼看懂，说明要写清"什么时候该用它"。
工具出错时应该返回一句人能看懂的话，而不是直接让程序崩——因为这句话要交给模型读，它才知道下一步怎么办。

## 防幻觉
要求模型"只根据资料回答，资料里没有就说没有提到"，比事后纠错更有效。
报告里的每个结论都应该能指回原文片段（带来源），这样才可验证。
